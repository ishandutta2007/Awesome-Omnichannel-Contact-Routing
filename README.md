# Awesome-Omnichannel-Contact-Routing

## Top Omnichannel Contact Routing Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Intelligent Work Distribution, Skill-Based Routing & Unified Contact Center Orchestration*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Omnichannel Contact Routing Tools**. These tools intelligently distribute customer interactions — voice, email, chat, SMS, social, and messaging — to the right agents based on skills, availability, priority, and real-time workload, while providing queue management, SLA tracking, and routing analytics.

**Examples** include Salesforce Omni-Channel Routing, Genesys Cloud CX, NICE CXone, Twilio TaskRouter, Talkdesk Omnichannel, Five9 Intelligent Routing, 8x8 Contact Center, AWS Amazon Connect, Freshdesk Omnichannel, and Zendesk Omnichannel Routing (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom routing logic, and transparent queue orchestration — ideal for contact centers, BPOs, and developers building data-sovereign routing infrastructure.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Sector Overview & Market Dynamics

The global Contact Center as a Service (CCaaS) market is estimated at approximately **$8.0B – $9.5B in 2026** (with the broader contact center software market exceeding **$50B+**), expanding at a CAGR of ~17–19%. The market is **moderately concentrated** at the top tier—where leaders like Amazon Web Services, Salesforce, Genesys, NICE, and Five9 capture ~45% of enterprise spend—yet remains **fragmented across mid-market and specialized verticals** due to the proliferation of conversational AI agents, open APIs, and regional compliance requirements.

## Open-Source GitHub Projects

- **[Chatwoot](https://github.com/chatwoot/chatwoot)**  
  Open-source omnichannel customer engagement platform with agent assignment, team inboxes, and routing rules. Self-hosted alternative to Zendesk and Intercom. MIT licensed.

- **[Zammad](https://github.com/zammad/zammad)**  
  Open-source helpdesk and ticketing system with omnichannel routing, skill-based assignment, and SLA management. Enterprise-grade alternative to Zendesk.

- **[FreeScout](https://github.com/freescout-helpdesk/freescout)**  
  Open-source help desk and shared inbox with auto-assignment, team routing, and multi-channel support. Lightweight alternative to Help Scout.

- **[osTicket](https://github.com/osTicket/osTicket)**  
  Open-source ticketing system with agent routing, department queues, and SLA-based assignment for email and web forms.

- **[UVdesk](https://github.com/uvdesk/community-skeleton)**  
  Open-source helpdesk system built on Symfony with ticket routing, agent assignment, and multi-channel support.

- **[Helpy](https://github.com/helpyio/helpy)**  
  Open-source customer support platform with ticket routing, knowledge base, and multi-channel intake.

- **[Tiledesk](https://github.com/Tiledesk/tiledesk)**  
  Open-source conversational platform with chatbot routing, human handoff, and omnichannel queue management.

- **[Rasa](https://github.com/RasaHQ/rasa)**  
  Open-source conversational AI framework with routing logic for intent-based handoff to human agents or departments.

- **[Botpress](https://github.com/botpress/botpress)**  
  Open-source chatbot platform with human-in-the-loop routing and omnichannel deployment (web, WhatsApp, Messenger, Slack).

- **[Typebot](https://github.com/baptisteArno/typebot.io)**  
  Open-source conversational form builder with routing logic and webhook-based agent handoff.

- **[LibreChat](https://github.com/danny-avila/LibreChat)**  
  Open-source chat platform with multi-agent routing, custom endpoints, and channel-based message distribution.

- **[Jitsi](https://github.com/jitsi/jitsi)**  
  Open-source video conferencing platform with SIP gateway and room-based routing for voice/video contact flows.

- **[Asterisk](https://github.com/asterisk/asterisk)**  
  Open-source PBX and telephony engine with ACD queues, IVR routing, and skill-based call distribution.

- **[FreeSWITCH](https://github.com/signalwire/freeswitch)**  
  Open-source telephony platform with call routing, queue management, and multi-channel contact center capabilities.

- **[Kamailio](https://github.com/kamailio/kamailio)**  
  Open-source SIP server for large-scale voice routing, load balancing, and contact center telephony infrastructure.

- **[OpenSIPS](https://github.com/OpenSIPS/opensips)**  
  Open-source SIP proxy with routing logic, failover, and load balancing for voice contact centers.

- **[ViciDial](https://github.com/vicidial/vicidial)**  
  Open-source predictive dialer and contact center suite with ACD routing, queue management, and agent assignment.

- **[Wazo Platform](https://github.com/wazo-platform)**  
  Open-source unified communications platform with call routing, queues, and omnichannel contact center APIs.

- **[FusionPBX](https://github.com/fusionpbx/fusionpbx)**  
  Open-source multi-tenant PBX with call queues, ring groups, and time-based routing for contact centers.

### Additional Strong Open-Source Options

- **[Apache Camel](https://github.com/apache/camel)** — Integration framework with routing patterns (EIP) adaptable for message and task distribution.
- **[Temporal](https://github.com/temporalio/temporal)** — Workflow engine for building durable, scalable routing and escalation logic.
- **[Camunda](https://github.com/camunda/camunda-bpm-platform)** — BPMN workflow engine for designing complex routing and approval flows.
- **[Node-RED](https://github.com/node-red/node-red)** — Flow-based programming tool for building custom routing dashboards and integrations.
- **[n8n](https://github.com/n8n-io/n8n)** — Workflow automation platform with routing nodes for multi-channel task distribution.
- **[Apache Airflow](https://github.com/apache/airflow)** — Workflow orchestration for scheduled routing, escalation, and reporting tasks.
- **[Keycloak](https://github.com/keycloak/keycloak)** — Identity and access management for agent authentication and role-based routing permissions.
- **Queue libraries** (RabbitMQ, Kafka, Redis Streams) for high-throughput task distribution and backpressure handling.
- Many community **ACD**, **IVR**, and **skills-based routing** modules for Asterisk and FreeSWITCH.

**Frameworks for building custom systems**: Combine **Chatwoot** or **Zammad** for ticketing, **Asterisk/FreeSWITCH** for voice routing, **Rasa/Botpress** for AI handoff, **Temporal** for durable workflow routing, and **Grafana + Prometheus** for real-time queue analytics to build a complete self-hosted omnichannel contact routing stack.
